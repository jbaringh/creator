# Plan: OpenAPI → POJO page

## Goal

Add a third page that accepts an OpenAPI 3.x spec (YAML **or** JSON), pasted, and emits Java POJOs — one class per entry in `components.schemas` — with the exact same output style as the JSON→POJO page (Lombok, `@JsonPropertyOrder`, optional `@JsonInclude`, nested static classes, sorted imports).

## Context

- Existing `pojo-generator.ts` is **value-based** (infers types from JSON data). OpenAPI is **schema-based** (types are declared). Different engine, same *output shape*.
- `components.schemas` = map of `name → schema`. Each becomes a top-level `public class Name`.
- No YAML parser installed. `js-yaml`'s `yaml.load()` parses both YAML and JSON (YAML is a superset) → single code path.
- CodeMirror has `java` + `json` lang packs. Input is YAML/JSON → add `@codemirror/lang-yaml` for input highlighting.

## OpenAPI → Java type map

| OpenAPI | Java |
|---|---|
| `string` | `String` |
| `string` + `format: date` | `java.time.LocalDate` |
| `string` + `format: date-time` | `java.time.OffsetDateTime` |
| `string` + `enum: [...]` | nested `public enum` (value name = prop name) |
| `integer` | `int` (or `long` if `format: int64`) |
| `number` | `double` (or `float` if `format: float`) |
| `boolean` | `boolean` |
| `array` / `items: X` | `List<X>` |
| `$ref: '#/components/schemas/Foo'` | `Foo` (last path segment) |
| `object` / has `properties` (inline) | nested `public static class` (name = capitalized prop) |
| `allOf: [...]` | merge sub-schema properties → nested class |
| `oneOf` / `anyOf` | `Object` (v1) |
| `nullable: true` | (handled by `@JsonInclude`; no extra annotation) |

## Output shape (per class)

```java
@JsonPropertyOrder({"a", "b"})
@JsonInclude(JsonInclude.Include.NON_NULL)   // only if includeMode set
@Data @NoArgsConstructor @AllArgsConstructor @Builder   // only if useLombok
public class Foo {
    @JsonProperty("a")
    private Bar a;

    @JsonPropertyOrder({"x"})
    ...
    public static class Bar { ... }

    public enum Color { RED, GREEN, BLUE }
}
```

Imports collected globally across all classes, emitted once at the top (sorted).

## Out of scope (v1)
- `oneOf`/`anyOf` → real unions (emit `Object`).
- `@NotNull`/validation from `required` (Jackson POJOs don't need it).
- Discriminator-based polymorphism.
